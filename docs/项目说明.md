# 项目说明

## 一、项目概述

本项目为高校校园自习室预约与座位管理系统，使用 Spring Boot 3 + Vue 3 前后端分离架构实现，适合作为课程设计、毕业设计、学习练手项目。

## 二、功能模块

### 1. 学生端

- 用户注册、登录、个人资料修改
- 查看自习室与座位详情
- 按日期/时段预约座位
- 支付扣费与优惠规则
- 查看预约记录与支付记录
- 发起投诉并查看处理结果
- 发布帖子、评论和点赞
- 座位调换申请
- 查看公告

### 2. 管理端

- 用户管理
- 自习室管理
- 座位管理
- 预约审批
- 投诉处理
- 公告管理
- 论坛管理
- 支付管理
- 收费标准配置
- 数据统计分析

## 三、数据库设计

数据库命名：`campus_reservation`

核心表包括：

- `user`
- `study_room`
- `seat`
- `reservation`
- `notice`
- `complaint`
- `forum_post`
- `forum_comment`
- `payment`
- `pricing_rule`
- `seat_swap_request`
