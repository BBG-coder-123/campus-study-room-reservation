# 校园自习室预约管理系统

基于 Spring Boot 3 + Vue 3 的前后端分离校园自习室预约管理系统，适合作为高校信息管理类毕业设计、课程设计与全栈开发学习项目。

## 1. 项目概述

本项目面向高校校园场景，围绕“自习室资源预约”展开设计与实现，重点解决学生在学习场景中查找座位、预约使用、支付、反馈以及管理员管理运营等一系列问题。系统以自习室预约为核心业务，覆盖学生端和管理员端两类用户角色，具备完整的业务闭环和后台管理能力。

项目采用前后端分离架构，后端基于 Spring Boot 3、MyBatis-Plus 和 Spring Security + JWT，前端基于 Vue 3 + Vite + Pinia + Element Plus，数据库采用 MySQL 8。系统功能涵盖用户管理、自习室与座位管理、预约处理、投诉反馈、论坛交流、公告发布、支付管理、收费规则设定和数据统计等多个模块。

## 2. 设计背景与研究意义

当前高校学习空间资源日益紧缺，传统线下排队、现场登记或人工电话预约方式已无法满足学生对高效管理和信息化服务的需求。高校自习室资源管理存在以下典型痛点：

- 自习室座位利用率低下且缺少精细化统计分析
- 学生难以实时查询座位占用情况
- 预约流程不透明，容易出现冲突与重复预约
- 管理人员缺乏统一后台，导致人工审核和数据维护效率低
- 反馈与投诉渠道不集中，服务质量难以持续提升

本系统通过信息化手段提高自习室管理效率，优化资源配置，提升学生体验，并为学校数字化校园建设提供一套可复用的管理示例。

## 3. 系统目标

### 3.1 总体目标

构建一个具备完整业务逻辑、清晰模块划分、可扩展架构的校园自习室预约管理平台，实现以下目标：

- 提升学生预约效率与使用体验
- 提高自习室资源利用率
- 简化后台管理与审核流程
- 规范投诉、公告和论坛等场景的运营工作
- 形成适合毕业设计展示的工程化项目结构

### 3.2 功能目标

- 学生端：注册登录、查看自习室、座位查询、预约、支付、取消、个人信息管理、投诉和论坛互动
- 管理端：用户管理、自习室座位配置、预约审批、投诉处理、公告管理、论坛审核、统计分析等

## 8. 本地运行说明

### 8.1 后端启动

```bash
cd backend
mvn clean package
mvn spring-boot:run
```

### 8.2 前端启动

```bash
cd frontend
npm install
npm run dev
```

### 8.3 数据库初始化

在 MySQL 中创建数据库并执行：

```sql
source db/schema.sql;
source db/data.sql;
```
